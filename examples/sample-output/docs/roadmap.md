# Roadmap

*Move items between sections rather than deleting them — a deleted "deferred" item loses the record that it was deliberately not built.*

## MVP scope
- Create, assign, and update status of tasks
- Single-team workspace (no multi-tenancy yet)
- Email notification on assignment

## Deferred (explicitly out of scope for now)
- Multi-workspace/team support — the data model isn't designed for tenant isolation yet, don't build features assuming it
- Recurring tasks
- Mobile app — web-only for now

## Open questions
- Whether task comments are needed for v1 or can wait
