# pickup-desk

A counter-service app for a bakery: staff take orders, customers pick them up. Plain Node, no
dependencies, no build step. Server-rendered HTML.

## Commands
- Run the tests: `npm test`
- Run one file: `node --test test/orders.test.js`
- There is no type-checker and no linter configured.
